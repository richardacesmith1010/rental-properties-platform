- Sprint 122 hotfix dispatched to switch the check from `/v1/accounts` (LIST) to `/v1/account` (singular, `capabilities.transfers === "active"`)

### `cron_runs` empty despite Sprint 39 wiring
- `apps/web/app/api/cron/generate-charges/route.ts` writes to `cron_runs` on every invocation (verified in compiled bundle)
- `cron_runs` row count: 0
- Implication: cron is not firing in production. Possible causes (in order):
  - `CRON_SECRET` not set in Vercel env → Vercel cron requests get 401
  - Vercel plan tier — Hobby caps at 2 daily crons; `vercel.json` now declares 3 (`generate-charges`, `keep-alive`, `verify-stripe-accounts`)
  - Cron silently fails after auth (less likely given the test)
- **Action item for user:** Verify `CRON_SECRET` is set in Vercel + check Vercel plan

- Across the lifetime of Domus, exactly 1 payment recorded

- Confirms: real money flow has never worked end-to-end except once
