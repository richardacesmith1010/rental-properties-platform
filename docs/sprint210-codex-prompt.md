# Sprint 210 — iPhone app, part 1: Capacitor shell for domusbase.com (L3 by owner exception) · Category: Platform / Phone app

## 1. Objective
Create a native iPhone app named **Domus** that runs the live Domus web app (https://domusbase.com) inside a Capacitor iOS shell, so Alia and owners use Domus as a real app, not a website on a phone.

This sprint delivers the foundation:
- the Capacitor project, app icon, launch screen and status bar;
- a friendly "no connection" screen;
- external links opening outside the app;
- the web app knowing it's inside the app, and adapting.

It must build and run on the iOS Simulator. Later sprints will add Face ID, push notifications, deep links and App Store submission.

## 2. Context (HEAD main)
- **Web app:** Next.js 15 in `apps/web` (npm workspace `@domus/web`), deployed at https://domusbase.com.
  - Auth is Supabase email/password with cookies. There's no OAuth.
  - Payments use Stripe Checkout, which redirects to `checkout.stripe.com`. Connect onboarding goes to `connect.stripe.com`.
  - `app/layout.tsx` already has `viewportFit: "cover"`, `appleWebApp`, `manifest: "/manifest.json"`, and `themeColor: "#7c3aed"` (outdated purple; the brand accent is `#1D4ED8`).
  - Safe-area insets are already used in the bottom bars, drawers and sidebar.
  - `components/pwa/install-prompt.tsx` registers `public/sw.js` and shows an "install" prompt.
  - `public/icons/` is empty. There are no app icons anywhere.
- **Old app:** `apps/mobile` is an archived Expo app. Don't touch it, delete it, or reuse it.
- **Root `package.json` workspaces:** `["apps/web"]`. Keep the iOS project **out** of the workspaces so the web gate and CI stay unchanged.
- **Machine:** macOS 26.6, Node 24.
  - **Xcode is being installed now** (the command-line tools only right now). Claude will run Xcode and Simulator builds. If `xcodebuild` isn't available to you, still produce a complete project and say so in the report.
- **Current releases (npm, 2026-10-09):** `@capacitor/core`, `cli` and `ios` 8.5.3; `splash-screen` 8.0.2; `status-bar` 8.0.4; `app` 8.1.2; `browser` 8.0.5; `@capacitor/assets` 3.0.5. Use Capacitor 8 with Swift Package Manager (no CocoaPods; `pod` isn't installed).

## 3. In scope
1. **New project `apps/ios`** (its own `package.json` named `@domus/ios`, private, with its own lockfile; not a root workspace):
   - Dependencies: `@capacitor/core`, `@capacitor/ios`, `@capacitor/app`, `@capacitor/browser`, `@capacitor/splash-screen`, `@capacitor/status-bar`.
   - Dev dependencies: `@capacitor/cli`, `@capacitor/assets` (plus `sharp` only if needed to render the icon).
   - Scripts: `sync` (`cap sync ios`), `open` (`cap open ios`), `assets` (generate icons and splash).
   - `capacitor.config.ts`:
     - `appId: "com.domusbase.app"`, `appName: "Domus"`, `webDir: "www"`;
     - `server: { url: "https://domusbase.com", cleartext: false, allowNavigation: [] }` (add only the hosts the shell must keep in-app, which is just domusbase.com);
     - `ios: { contentInset: "never", scheme: "Domus", limitsNavigationsToAppBoundDomains: false, appendUserAgent: "DomusApp/1" }`;
     - plugin config for SplashScreen (show until the web app is ready, maximum 3 s, background `#FFFFFF` light / `#121316` dark if supported) and StatusBar (overlays the web view).
   - `www/index.html`: the bundled **fallback / offline page**. Plain HTML/CSS in Domus colors, with the Domus wordmark and the text `No internet right now.` / `Check your connection, then try again.` plus a `Try again` button that reloads https://domusbase.com. Light and dark via `prefers-color-scheme`. Tap target ≥ 44 px.
   - **Load-failure handling:** if the remote URL fails to load (offline, DNS or timeout), show the bundled offline page instead of WebKit's error. Use Capacitor's supported `server.errorPath` if Capacitor 8 has it; otherwise use the smallest native hook in `AppDelegate`/a `CAPBridgeViewController` subclass. Note which one you used.
   - **App icon:** a 1024×1024 PNG generated from a new SVG at `apps/ios/resources/icon.svg`: a rounded-square blue (`#1D4ED8`) background with a simple white house glyph. No text, no gradient, no transparency in the final PNG. The splash is the same glyph on white (light) or `#121316` (dark). Generate all sizes with `@capacitor/assets` into the Xcode asset catalog.
   - **The iOS project** (`ios/App`, generated by `npx cap add ios`, then committed):
     - display name `Domus`;
     - deployment target as Capacitor 8 requires (state it);
     - portrait only on iPhone, all orientations on iPad (or iPhone only, if simpler; say which);
     - `Info.plist` without any unused permission strings.
   - `apps/ios/README.md`: how to sync, open, run on the Simulator, and change the URL for a local dev server (`CAP_SERVER_URL` environment override in `capacitor.config.ts`, defaulting to production; reject any non-https URL except `http://localhost` / `127.0.0.1`).
2. **Links that leave Domus** (a small native-bridge script injected by the web app, see item 3):
   - Links to other hosts (`mailto:`, `tel:`, `sms:`, and any https host that isn't domusbase.com, the Supabase project URL or Stripe Checkout/Connect) open via `@capacitor/browser` (an in-app Safari sheet) or the system handler for `mailto:`/`tel:`.
   - **Stripe Checkout and Connect stay in the web view** so their return URLs come back to domusbase.com inside the app.
3. **The web app knows it's inside the app** (`apps/web`):
   - A small helper `lib/native-app.ts` with `isNativeApp()`, true when the user agent contains `DomusApp/`. It's safe on the server: read `headers()` `user-agent` in server code, `navigator.userAgent` on the client.
   - In the app: **don't register `sw.js`, and hide the PWA install prompt** (`components/pwa/install-prompt.tsx`).
   - In the app: add `class="domus-native"` to `<html>` (from the server via the user-agent header, so there's no flash). In `globals.css`, `.domus-native` turns off text-selection callouts on buttons and links, and turns off tap highlight. Use no other visual changes; layouts already use safe-area insets.
   - Update `themeColor` to the brand accent with light and dark values (`#FBFBF9` / `#121316` for browser chrome, or the accent; pick the one that looks right under a translucent status bar and say why). Update `manifest.json` `theme_color` the same way, and add `icons` (192, 512, maskable 512, `apple-touch-icon` 180) produced from the same SVG into `apps/web/public/icons/`. Reference the apple-touch-icon in metadata.
   - The client-side link-handling script from item 2 lives in `components/native/native-bridge.tsx`. It's mounted once in the root layout and is a no-op outside the app. It must not import `@capacitor/*` into the web bundle: use `window.Capacitor?.Plugins` at runtime, with typed guards.
4. **Tests (web):**
   - `isNativeApp` (server and client user agents);
   - no SW registration or install prompt in the app, unchanged outside it;
   - the `domus-native` class is applied only in the app;
   - native-bridge link routing (external host → Browser.open; domusbase.com, Stripe and Supabase → default; mailto/tel → system; no-op outside the app);
   - the theme color and manifest icons exist.
