# Domus stage gates

A stage opens only when every box for it is checked with evidence (file, link or live check). Run `/risk-review`
before each gate. Current stage: **0 → family (own homes + family)**.

## Gate 1 — Outside testers (people who aren't family)
- [ ] Sign-up and invite flows require "I agree" and record the Terms version (rules map: Contract formation)
- [ ] Terms and Privacy rewritten: Denver courts, liability cap, indemnity, payment agency, required privacy items
- [ ] Late fees follow each user's state rules; no automatic fee where rules aren't set up
- [ ] No tenant card fee (landlord pays card cost)
- [ ] Disputes, refunds and failed bank payments handled; LLC withdrawals paused or redesigned
- [ ] Reminder disclaimers live; account-deletion confirmation sent
- [ ] Vercel Pro; Sentry DPA accepted; backup claim true
- [ ] Final product name chosen; domains registered
- [ ] Rules map: no GAP rows in areas outside testers will use
- [ ] Rules map rows researched for every state with a real home (today CO, SC, IL, PA)

## Gate 2 — App Store submission
- [ ] Gate 1 complete
- [ ] LLC formed under the final name; D-U-N-S; Apple membership converted to organization
- [ ] App Privacy label matches the privacy policy (claims audit)
- [ ] Trademark application filed (classes 9, 42, 36)

## Gate 3 — Paying customers
- [ ] Gates 1–2 complete
- [ ] Pricing decided; 30-day notice given to current users
- [ ] Stripe and Plaid moved to the LLC; insurance bound (tech E&O + cyber, general liability)
- [ ] Stripe 1099 reporting on; sales-tax check for subscriptions in each state with customers
- [ ] Subscription purchase path complies with Apple 3.1.1 / 3.1.3 (in-app purchase or web-only)
- [ ] Supabase Pro (backups)

## Gate 4 — A new state
- [ ] Rules map rows for that state (late fees, deposits, notices, screening, fees) researched and verified
- [ ] State rules configured in the product before any lease there uses automatic fees
