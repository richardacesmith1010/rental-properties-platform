# Roadmap

## Phase 1 (Current Scaffold)
- Monorepo structure
- Shared domain model types
- Web dashboard shell
- Mobile shell
- Supabase relational schema and baseline RLS

## Phase 2
- Authentication and role-aware access (owner, manager, tenant)
- CRUD for properties, units, tenants
- Rent charge generation and payment logging

## Phase 3
- Maintenance ticket lifecycle
- File uploads for leases and receipts
- Communication history and reminders

## Phase 4
- KPI reporting (cash flow, delinquency, occupancy)
- Push + SMS + email notifications
- Basic accounting export
